# CareerPilot AI

Build a modern, premium SaaS web application called **CareerPilot AI**.

The platform is an AI-powered career pivot coach that helps students and job seekers understand their current skills, identify skill gaps for their desired career, generate personalized learning roadmaps, and track job applications.

TECH STACK:
- React
- TypeScript
- Tailwind CSS
- Shadcn UI
- Lucide React icons
- Recharts for analytics and graphs
- Supabase-ready architecture for authentication and database

DESIGN SYSTEM:
Create a polished, professional dashboard inspired by Linear, Notion, and modern SaaS platforms.

Colors:
- Sidebar: #111827
- Main background: #F8FAFC
- Primary accent: #635BDB
- Secondary accent: #16A085
- Main text: #172033
- Secondary text: #64748B
- Borders: #E5E7EB
- Cards: white

Use Inter font, rounded cards, subtle shadows, clean spacing, clear typography, and minimal gradients.

GLOBAL LAYOUT:
Create a reusable dashboard layout with:
- Dark navy sidebar
- CareerPilot AI logo and name
- Navigation links
- Overview
- Skill Analysis
- Learning Roadmap
- Applications
- Profile and Settings at the bottom
- Main content area
- Top navigation bar with page title, notifications icon, and profile avatar

Create responsive layouts for desktop, tablet, and mobile.

IMPORTANT:
- Every navigation link must work.
- Use reusable components.
- Use realistic demo data initially.
- Make all buttons interactive wherever possible.
- Do not create dead buttons.
- Do not pretend that AI functionality is connected if it is not.
- Keep the code organized and easy to integrate with Supabase and a Python FastAPI backend later.

Create the overall project structure and all the main pages. We will improve each page individually in subsequent prompts.
